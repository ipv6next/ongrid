# Phase 2 P1 开发计划

## 目标

P1 的目标不是扩菜单，而是把 Ongrid 已经跑通的能力组织成政企安全运维闭环：

告警进入事件 -> 自动调查/RCA -> 建议动作 -> 人工确认/审批 -> 处置状态 -> 审计留痕 -> 报告归档。

ITOps 只作为产品经验素材，优先吸收它在审批、巡检、报告、告警降噪和审计上下文方面的页面组织方式。

## 信息架构

主导航保持：

| 导航 | 作用 |
|---|---|
| AI 助手 | 对话、深度诊断、工具调用入口 |
| 仪表板 | 安全态势、待处置事件、巡检风险、Edge/LLM 可用性 |
| 事件 | 告警、Incident、RCA、处置闭环 |
| 资产 | Edge/设备/业务系统/负责人/等级/运维窗口 |
| WebShell | 浏览器终端、会话上下文、命令审计 |
| 审计 | WebShell、AI tool、RCA、配置变更、处置闭环审计 |
| 报告 | 巡检报告、RCA 报告、周/月报告 |
| 设置 | LLM、凭证、集成、系统健康 |

Ongrid 能力区保留：

| 导航 | 作用 |
|---|---|
| Skill 管理 | 技能目录、工具能力、风险等级、审批要求、测试状态 |
| Agent | 智能体角色、允许工具、系统提示词 |
| 工作流 | 自动化编排和定时任务 |
| 知识库 | 经验沉淀、RCA/复盘入库 |
| MCP | 外部工具连接 |
| 拓扑 | 影响范围和关联关系 |
| 指标 | Prometheus/Grafana 指标入口 |
| 日志 | Loki 日志入口 |

## P1 批次

### Batch 1：事件闭环

状态：已开始。

范围：

- 事件详情顶部增加“事件处置闭环”面板。
- 串联 Ack、RCA、人工确认、报告输出。
- 保留 Ongrid investigator，不另起 ITOps RCA 体系。
- 从 RCA 证据链跳审计、会话、tool call。
- RCA ready 后支持复制/导出 Markdown。

验收：

- 打开任意 Incident 能看到闭环四步。
- RCA ready 时能复制/下载 RCA。
- 人工确认入口能跳到 Approvals。
- 审计上下文入口带上 investigation/session 过滤。

### Batch 2：事件列表增强

范围：

- 将“告警中心”融合为事件入口。
- 增强筛选：状态、严重级别、RCA 状态、是否待确认、是否已报告。
- 增强分派/SLA 字段的 UI 占位，不急于做复杂后端。
- 列表行显示：是否自动调查、置信度、建议动作数量、最近处置动作。

验收：

- 事件列表能快速筛出“待确认”“未 RCA”“未闭环”。
- 从列表进入详情后上下文连续。

### Batch 3：人工确认/审批

范围：

- 把“审批中心/自愈工作台”命名收敛为“人工确认”。
- 待确认项按 Incident/RCA/Skill/Workflow 来源分组。
- 展示建议动作来源、风险等级、payload、执行结果。
- 高风险 Suggested Action 默认进入人工确认，不默认自动执行。

验收：

- 能看到待确认动作来自哪个事件或会话。
- Approve/Reject 后有审计记录。
- 事件详情能反映待确认状态。

### Batch 4：报告系统增强

范围：

- 报告页建立三个基础模板：巡检报告、RCA 报告、周/月报告。
- RCA 报告从 Incident/Investigation 生成。
- 巡检报告从 SecurityPatrol 结果生成。
- 周/月报告继续复用 Ongrid Report domain，接真实 incident/audit/asset 数据。

验收：

- 事件详情能生成或归档 RCA 报告。
- 巡检完成后能生成巡检报告。
- 报告页能按类型和状态筛选。

### Batch 5：巡检中心增强

范围：

- Phase 1 巡检 MVP 扩展为模板 + 历史记录。
- 模板首批：SSH 配置、弱口令风险提示、开放端口、sudoers、系统账号、登录失败、防火墙、关键服务、资源使用、最近变更。
- 继续用 Ongrid Edge/Skill 执行，只读优先。

验收：

- 可选模板运行巡检。
- 巡检结果可进入报告。
- 每次巡检写入审计。

### Batch 6：审计增强

范围：

- 增加过滤：WebShell、AI tool、RCA、配置变更、处置闭环、报告导出。
- 从事件详情/RCA/tool call 跳转到审计页时自动带过滤条件。
- 审计详情展示 payload 摘要和上下文回跳。

验收：

- WebShell 命令、AI tool call、Ack/Resolve、报告导出都能在审计中查到。
- 从 RCA 证据链跳审计无需切组织才能看到数据。

### Batch 7：仪表板安全态势

范围：

- 吸收 ITOps 仪表板思路，但不做传统资源大盘。
- 增加：待处置事件、待确认动作、巡检风险、Edge 异常、LLM 可用性、最近 RCA。

验收：

- 登录默认首页能看到当前安全运维待办。
- 每张卡片都能跳到真实页面。

## 暂不进入 P1

- 远程桌面。
- 云管/虚拟机/容器全生命周期管理。
- DCIM/机房大屏。
- 默认自动修复执行。
- 传统脚本中心。
- 直接 SSH 凭证管理。

## Skill 管理定位

Skill 管理和 Agent 并列：

- Agent：谁来判断，带什么角色和提示词。
- Skill：能调用什么工具，是否只读，风险等级，是否需要审批，如何测试。

下一步增强 Skill 管理页：

1. 增加风险等级列：read / observe / mutate / high-risk。
2. 增加“是否需要审批”列。
3. 增加“最近调用/失败率/审计入口”。
4. 增加巡检模板关联：哪些 Skill 可被巡检中心编排。
